# RestutantAdminstratorandmenu
This project is a web application that contains two interfaces: one for the admin and one for the user. The app allows users to browse the food menu, view discounts, and explore everything related to the restaurant, while the admin interface allows the admin to manage all content displayed on the user interface.

## Technologies Used

- **Frontend:**
  - **HTML**: To structure the pages.
  - **CSS**: To style the pages and make the design attractive.
  - **JavaScript**: To add interactivity to the pages.
  - **jQuery**: To simplify DOM manipulation and AJAX requests.

- **Backend:**
  - **ASP.NET MVC**: To build the app using the Model-View-Controller pattern.
  - **C#**: The programming language used for backend development.

## Project Components

### 1. **User Interface**
   - **Multiple Pages for Food Display**: Users can browse through a variety of food items available in the restaurant.
   - **Discounts Section**: Displays current promotions and discounts offered by the restaurant.
   - **Menu Details**: Users can view detailed information about each dish, including ingredients, pricing, and nutritional facts.
   - **Order Page**: Allows users to add dishes to their cart and place an order.

### 2. **Admin Interface**
   - **Dashboard**: Admins can add, edit, or delete dishes from the menu.
   - **Menu Management**: Admin can update food items, their details, and prices.
   - **Discount Management**: Admin can manage ongoing discounts and promotions.
   - **Order Management**: Admin can view and manage user orders placed through the platform.
